# JDBC Operations

This project demonstrates basic JDBC CRUD operations in Java.

## 📌 Features

- Retrieve records from database
- Update existing records
- Delete records from database

## 📂 Project Files

- Retrieve.java – Fetch data from database
- Update.java – Update existing records
- executeDelete.java – Delete records

## 🛠 Technologies Used

- Java
- JDBC
- MySQL (or any relational database)

## ⚙️ How to Run

1. Install Java (JDK 8 or above)
2. Install MySQL and create a database
3. Update database credentials in the Java files

### Compile
```
javac Retrieve.java
javac Update.java
javac executeDelete.java
```

### Run
```
java Retrieve
java Update
java executeDelete
```

## 📖 Description

This project is created for learning and practicing JDBC database operations.
